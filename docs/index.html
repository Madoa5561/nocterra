これは何か

灰冠が昇って以来、世界は薄暮に沈んだ。滅びかけたこの世界が ノクテラ。
時間は緩やかに止まり、死者は眠らず、九つの地域に九人の冠の者が君臨している。

プレイヤーは古代の門をくぐり、ノクテラへ踏み込む。目的は「帰ること」。 しかし進むほどに、この世界が滅びたのは誰かの意思ではなく、約束が果たされなかったからだという真実に近づいていく。

王道のメトロイドヴァニア進行

地域を巡り、冠の者を討ち、王の刻印を集める。集めた刻印が結末を分岐させる。

ドロップ → クラフト

敵が落とす素材を集めて武器を作る。装備が整うほど、危険な地域へ踏み込める。

サーバー権威の戦闘

スタミナ・回避・パリィ・武器戦技。すべてサーバー側で判定される。

物語

かつて世界を照らしていた始原の灯火が失われ、空に灰冠が昇った。 以来、世界はゆっくりと薄暮に沈み、死者は眠らなくなった。人々はそれを「ノクテラ（滅星界）」と呼ぶ。

九つの地域には、それぞれ冠の者が座している。彼らは滅びた王国の残響であり、 王の刻印を守っている。刻印は八つ、冠に戻るべき欠片。

折り返し地点：黒冠城

刻印が集まると、黒冠城の黒冠の玉座が応える。

  • 刻印5個以上 → 通常エンディング「薄暮は終わる」… 冠が緩み、灰の中に帰り道が開く。だがノクテラは残る。
  • 刻印8個 → 真エンディング「灯火の化身」… 冠の下にあったのは王ではなく、世界が忘れた約束だった。 失われたはずの始原の灯火を、あなたは運び出す。
エンディング後もワールドは続きます。探索・討伐・収集をそのまま継続できます。

ノクテラで出会う魂

灰の番人

灰樹の森の案内人。最初の依頼をくれる。初めてノクテラに来た者のそばに現れる。

湿原の未亡人

嘆きの湿原に住む。悲嘆の聖女の伝承と、その救い方を知っている。

盲目の書記

古代神殿に残された記録係。刻印と黒冠の王の真実を書き残した。

門番

黒冠城の前で刻印を数える。五つ揃えば、門を開ける。

灰の商人

瓦礫の中で商う。何を欲しがっているのかは、話してみてのお楽しみ。

迷い子

隠し要素。連れ帰ると、それなりの報酬がある。

9つの地域

各地域には固有の地形・植生・構造物と、地域の祭壇が生成されます。祭壇を右クリックすると、その地の冠の者が目覚めます。

灰樹の森

灰と枯れ木の森。古代神殿が眠り、腐朽の祭壇がある。

嘆きの湿原

霧に沈む沼地。墓所と未亡人が待つ。

黒冠遺跡帯

黒い廃墟。黒冠城と、その主が座す。

亡国の城塞跡

崩れた城壁の残骸。断罪の騎士長が巡回する。

紅砂の荒野

赤い砂丘と砂岩の露頭。水は無く、砂嵐が吹く。

深淵の海

暗い水の底。深淵の海帝が水陸を支配する。

星骸の浮島

紫の結晶と星屑。墜星竜アステルが空を舞う。

永劫の氷原

雪と氷の白い世界。白銀の処刑者が静かに待つ。

黒鉄の火山

マグマと黒石の地。灼鋼の巨神が炉を守る。

進み方 — ドロップとクラフト

ノクテラの装備は、敵が落とす素材から作るのが基本です。地域が危険なほど、得られる素材も強くなります。

灰装備一式（兜2／鎧4／脚甲3／具足1、合計防御力10）もドロップ素材から作れます。 革（7）と鉄（15）の中間で、序盤〜中盤の探索を支えます。

素材 14 種

一般モブからは 灰の繊維・亡霊の燐粉・沼鉄。 地域ボスからは 朽葉の樹脂・ベールの絹・墓土の塵・黄金の砂・潮の真珠・星屑の欠片・霜の結晶・火山の鱗（各地域 1 種）と、 全ボス共通の 砕けた冠片。深淵系は深淵の鱗、火系は火核も落とします。

武器は R 回避 / V 強攻撃 / F パリィ / G 武器戦技 で戦います。スタミナ管理が要。

スクリーンショット

ダウンロードと導入

必要なもの

  • Minecraft Java Edition 26.3
  • NeoForge 26.3.0.99
  • GeckoLib 5.5.7（26.3 対応版・必須）
  • Java 25（NeoForge 26.3 の要件）

手順

  1. NeoForge 26.3.0.99 を導入した Minecraft 26.3 を用意する
  2. mods/ フォルダに GeckoLib 5.5.7 と nocterra-*.jar を入れる
  3. 起動（クライアント／専用サーバーどちらでも可）
Releases からダウンロード ソースコード

はじめかた

  1. エンバーシャードを作る（石炭＋火打石＋金インゴット）
  2. 古代の門の骨組みを作り、内側 2×3 以上の枠にする
  3. エンバーシャードを右クリックして点火 → 灰冠の門が開く
  4. 門に入るとノクテラへ。初回はタイトル演出と探索手帳が渡される
  5. 各地域の祭壇を右クリックして冠の者を目覚めさせ、討って刻印を集める
  6. 刻印5個で黒冠城へ。玉座で結末を見る（8個なら真エンディング）
