## 2. 世界観

滅星界ノクテラ。黒冠の王の禁忌の儀式で王国が滅び、永遠の薄暮に包まれた異世界。
プレイヤーはオーバーワールドの古代の門から侵入し、8地域のボスから「王の刻印」を奪って黒冠城を目指す。

- 刻印 8 個中 **任意の 5 個** → 通常エンディング
- **全 8 個** → 真エンディング分岐
- エンディング後もワールド探索継続可能

## 4. 戦闘

- リソース: スタミナ（初期 100、回避 25、強攻撃 15〜35、自然回復 毎秒 8 を設定可能）／魔力
- 行動: 回避（サーバー判定の無敵フレーム）、強攻撃、パリィ、コンボ、戦技、チャージ攻撃、姿勢崩し
- 状態異常、固有武器能力、遺物（最大 3 装着）
- 武器カテゴリ 11 種: 片手剣 / 大剣 / 双剣 / 槍 / 大槌 / 斧 / 鎌 / 弓 / クロスボウ / 魔導杖 / 魔導銃
- 最終目標 60 武器以上（一部に固有戦技・属性）
- キーバインドはプレイヤー変更可能

武器強化 +5 まで / 防具セット 12 種 / 魔法・戦技 24 種 / 遺物 30 種 / 素材は通常・希少・ボス素材の 3 層

## 6. 探索・物語

ダンジョン 30+ / 独自モンスター 40+ / 主要 NPC 12+ / クエスト 50+ / 世界イベント 16 / エンディング 3
探索手帳（発見したバイオーム・ダンジョン・ボス・NPC・収集品を記録）、NPC 会話・クエスト・進行はデータ駆動

## 7. ワールドシステム

- **侵食**: 蓄積で敵出現・幻影・魔法が変化。必ず低下手段を用意
- **黒月イベント**: 世界状態が一時変化。発生条件・頻度・難易度はサーバー設定で調整可
- **拠点**: NPC 保護で発展、ショップ・設備・クエスト解放
- **ストーリー分岐**: NPC 対応・収集情報で会話と結末が変化

## 8. 非機能要件

- 毎 tick 全エンティティ総当たり禁止、AI は距離・状態で更新頻度を調整
- メッシュ/テクスチャ/アニメーション再利用、パケット量抑制
- チャンク生成で同期的大量読み込みを起こさない、メモリリークなし
- 既存ワールドを破壊しない、既存 MOD との互換性維持
- 計測結果は PERFORMANCE.md、テストは自動/実機を分けて記録、未実施は明記
